# ADR-001: Adopt CLAP-Based Emotion Embeddings Instead of a Simple Valence–Arousal Model

**Status:** Accepted  
**Date:** 2025-11-16

## Context

Our project requires converting music segments into emotion-driven drone-swarm motion parameters. Early prototypes used only a 2-dimensional valence–arousal (V–A) model, but the output was too coarse for mapping to richer motion primitives (e.g., “grumpy”, “whimsical”, “exciting”).

We needed a method that:

- captures fine-grained emotional nuance, not just V–A;
- supports zero-shot labeling (users can add new labels like “sparkly”);
- works consistently across different genres and timbres;

The LAION-CLAP (Contrastive Language–Audio Pretraining) model provides 512-dimensional embeddings for both audio and text, enabling similarity-based zero-shot emotion classification.

## Decision

We adopt CLAP-based text–audio embedding similarity as the project’s core emotional representation, replacing the simple valence–arousal model as the primary descriptor for each music segment.

The V–A model remains available for secondary modulation (e.g., scaling velocity or jitter), but CLAP embeddings drive the main drone-motion personality mapping.

## Options Considered

### Option 1 — Use CLAP embeddings (Chosen)
- Extract audio embeddings per segment  
- Compare to a dynamic dictionary of text emotion labels  
- Support user-added labels via zero-shot text embeddings

### Option 2 — Use a simple valence–arousal model
- Compute V–A via regression or Essentia VAD features  
- Map V–A → drone parameters directly  
- No support for rich or extensible emotion vocabularies

### Option 3 — Build our own classifier
- Requires a labeled emotion dataset  
- Not feasible within the capstone timeline  

### Option 4 — Do nothing (baseline)
- Keep using fixed moods or random parameters  
- No meaningful emotion–motion link; low stakeholder value

## Decision Drivers

- Need richer emotional vocabulary for drone motion beyond 2D V–A  
- Need a method that supports labels like “whimsical”, “ethereal”, “aggressive”  
- Want zero-shot extensibility where users can add labels dynamically
- Avoid dependency on large supervised datasets  
- Must run on Windows hardware (team constraint)

## Rationale

CLAP provides:

- High-dimensional semantic information learned from large audio–text pairs  
- Zero-shot emotion classification via text embeddings  
- Windows/Python compatibility, unlike Essentia V-A model which does not have a Windows capatible version

## Consequences

### Positive
- Enables fine-grained personality mapping for drone motion  
- Supports adding new emotion labels without retraining  
- Allows richer mapping to Boids (cohesion, alignment, speed, jitter)  
- Produces more expressive and musically informed drone choreography

### Negative / Tradeoffs
- Higher computational cost than V–A regression  
- Requires maintaining a JSON dictionary of label prompts
